# Practical 1: Responsive Android Layouts

This repository contains the XML layouts for Part I and Part II of Practical 1.

| Part | Layout | XML file |
| --- | --- | --- |
| Part I | LinearLayout with weights | [activity_main.xml](app/src/main/res/layout/activity_main.xml) |
| Part II | ConstraintLayout with weights | [activity_main_constrain.xml](app/src/main/res/layout/activity_main_constrain.xml) |

Since the submission accepts only one GitHub repository URL, both XML files are included in this repository for assessment.

The app currently loads the Part I layout by default. The Part II layout can be reviewed in the XML file linked above.
